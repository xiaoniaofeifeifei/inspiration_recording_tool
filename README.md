# 闪记 / Sparkling

一个「打开就能记」的灵感记录器。核心只有一句话：**记录前不做任何决策**。

打开首页就是一个大录音按钮加一行文字输入，点一下就开始录、打完字回车就存。所有内容先落进
「新灵感」收件箱，归类发生在记录之后；保存卡片直接关掉也会保存，所以灵感不会因为误触丢掉。

## 快速开始

```bash
pnpm install
pnpm dev
```

浏览器打开终端里输出的地址即可。首次打开会自动建好一个示例笔记本，方便先看懂结构。

其他命令：

```bash
pnpm test        # 数据层单测（vitest + fake-indexeddb）
pnpm build       # 类型检查 + 生产构建
pnpm icons       # 重新生成 public/icons 下的 PWA 图标
```

### 手机上试用

`pnpm dev` 已经监听局域网地址，用手机连同一个 Wi-Fi 打开网络地址即可。但浏览器的录音接口只在
安全上下文里可用，所以手机上**录音**需要 HTTPS：

```powershell
$env:SPARKLING_HTTPS=1; pnpm dev
```

自签证书会提示不安全，手动信任一次即可。文字和图片记录不依赖 HTTPS。

## 数据存在哪

全部数据存在浏览器的 IndexedDB（库名 `sparkling`）里，没有后端、没有账号：

- `notebooks` 笔记本、`sections` 分区、`items` 灵感、`blobs` 录音/图片二进制
- 「新灵感」是内置的虚拟收件箱（固定 id `__inbox__`），不属于任何笔记本
- 一条灵感 = 可选标题 + 自由文本 + 任意多个附件（录音和图片可以混在一起）

注意：清除浏览器数据、换设备或换浏览器都会丢，第一版接受这个代价。

## 目录结构

```
src/
  db/          # 数据层，唯一直接操作 IndexedDB 的地方（含 seed 与单测）
  lib/         # 录音 hook、图片压缩、格式化、通用 hooks
  store/       # zustand 全局状态：草稿、归类目标、toast、笔记本缓存
  components/  # 保存卡片、归类选择器、附件预览、侧边栏等
  pages/       # 首页记录、新灵感、全部灵感、笔记本、灵感详情
```

## 第一版做了什么

- 首屏零决策记录：点一下开录（计时 + 音量波形），再点停止；打字回车即存；拍照/相册一键压缩入库
- 保存卡片：默认选中「新灵感」，可就地新建笔记本/分区；关掉卡片同样保存，并提示「已存到 X · 更改」
- 三层组织：笔记本 → 分区 → 灵感，收件箱单独置顶
- 灵感详情：文本自动保存、继续追加录音/图片、删除附件、移动归类、删除整条
- 全部灵感：标题 + 正文关键词搜索，按「有录音 / 有图片 / 纯文字」和时间范围筛选
- 响应式：手机单栏 + 底部导航，≥1024px 左侧边栏
- PWA manifest 与图标，可以「添加到主屏幕」

## 第一版明确不做

账号登录与云同步、语音转文字、标签、导出备份、任意文件上传、链接收藏、回收站/撤销删除、
深色模式、协作分享。
